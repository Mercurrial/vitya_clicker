# ВИТЯ ГОНИТ

Idle-игра про друга, который гонит самогон в гараже и постепенно доходит
до орбитального самогонного коллайдера.

Витя — не посмешище. Он мастер, у которого просто очень специфическое
ремесло. Игра относится к нему серьёзно, и шутит редко — ровно поэтому
шутки работают.

---

## Как поставить на телефон

Android, файлом, без Google Play:

1. Скинуть `app-release.apk` на телефон (Telegram самому себе — проще всего).
2. Открыть файл. Android спросит разрешение ставить из этого источника —
   разрешить.
3. Поставить, открыть. Иконка — банка с самогоном.

Сборка подписана отладочным ключом. Это нормально для раздачи файлом:
следующая версия поставится поверх и прогресс сохранится. Играть можно
офлайн, интернет не нужен вообще.

Прогресс лежит в памяти приложения. Удалишь приложение — удалится и гараж.

---

## Как играть

Коротко, чтобы не читать двадцать минут:

- **Тап по Вите** — подкинуть дров. Даёт самогон и поднимает **ГРАДУС**.
- **ГРАДУС** держи в подсвеченном окне — тогда растёт **СОРТ**. Перегрел —
  сорт горит. Забросил — медленно сползает.
- **СОРТ** — это цена за литр и доступ к покупателям. Первач берёт сосед за
  бесценок, «Дедов запас» ждут на свадьбе.
- **БАК** копит самогон, пока не переполнится. Ёмкость растёт вместе с
  производством — стоять над кнопкой не нужно.
- **ПОХМЕЛЬЕ** — сброс гаража ради мудрости. Мудрость множит всё навсегда.
- **ДОСТИЖЕНИЯ** открывают удобства: автопродажу, покупку пачками.

Игра не наказывает за отсутствие: пока телефон в кармане, аппарат работает.

## Разработка

Flutter 3.24.3 / Dart 3.5.3.

```bash
flutter pub get
flutter test        # 117 тестов
flutter analyze     # должно быть чисто
flutter run         # на подключённом устройстве
```

Сборки:

```bash
flutter build apk --release      # build/app/outputs/flutter-apk/app-release.apk
flutter build web --release      # build/web
```

Отладка в браузере — через свой сервер, а не `python -m http.server`:

```bash
python tools/serve.py
```

Он запрещает кэширование и вычищает service worker. Без этого браузер
показывает старую сборку, и на поиск несуществующего бага уходит вечер —
проверено.

Иконки и заставка рисуются кодом:

```bash
dart run tools/make_icons.dart
```

Пиксель-арт лежит прямо в `tools/make_icons.dart` строками: видно в диффе,
правится одним символом.

## Как устроено

```
lib/
  models/      состояние: ресурсы, генераторы, апгрейды, сорт, престиж
  engine/      правила игры — чистые функции, без побочных эффектов
  content/     что в игре есть: аппараты, улучшения, сорта, покупатели, реплики
  core/        сейвы, миграции, часы, форматирование чисел
  providers/   Riverpod: склейка движка, времени и интерфейса
  ui/          экран гаража, пиксель-арт, виджеты
```

Три правила, на которых всё держится:

**Движок не знает про интерфейс.** `GameEngine` — чистые функции
`состояние → состояние`. Поэтому баланс проверяется тестами за две секунды,
а не двадцатиминутным сеансом.

**Формула живёт в одном месте.** Офлайн-доход однажды разъехался с обычным
тиком и переполнил бак в тысячу раз — ровно под комментарием о том, что
формула тут одна. Теперь и тик, и офлайн идут через `GameEngine.creditOffline`.

**Миграции сейвов заморожены.** `lib/core/save.dart` — цепочка v1→v4. Старый
шаг никогда не переписывается под новые формулы, даже если формула изменилась:
он обязан читать то, что реально лежит на диске у игрока. Дублирование кода в
миграциях — намеренное.
