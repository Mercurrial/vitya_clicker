## Как поставить

### iPhone

Нативная сборка под iOS требует Mac с Xcode. Вместо неё — веб-версия: на
iPhone она ставится штатным способом и работает как обычное приложение.

1. Открыть ссылку в **Safari** (Chrome на iOS так не умеет).
2. «Поделиться» → **«На экран Домой»**.
3. Запускать с иконки. Адресной строки нет, интернет после первого
   открытия не нужен.

Ссылка одна на всех: каждый играет свой прогресс на своём устройстве.

### Android

1. Скинуть `app-release.apk` на телефон.
2. Открыть файл, разрешить установку из этого источника.
3. Поставить.

Сборка подписана отладочным ключом. Ключ менять нельзя: иначе следующая
версия не встанет поверх и прогресс потеряется.

### Про сохранения

Прогресс лежит на устройстве — в хранилище браузера или в памяти приложения.
Его можно потерять: очистив данные сайта, сменив телефон, удалив приложение.

На вкладке «Витя» есть **ПЕРЕНОС ПРОГРЕССА**: кнопка сворачивает гараж в
строку, которую можно отправить себе в сообщения, а «Вставить» разворачивает
обратно. Строка защищена контрольной суммой — обрезанный при копировании код
игра не примет молча.

## Как играть

| Что | Как работает |
|---|---|
| **ЖАР** | Зажать палец где угодно по гаражу — греется. Отпустить — стынет. На компьютере то же делает пробел. |
| **ОКНО** | Подсвеченный участок шкалы. Пока жар в нём, копится СЕРИЯ. Перегрел — серия сгорает. |
| **СЕРИЯ** | Множитель ко всему производству, до ×3. Не срывается сразу: три секунды держится, потом тает. |
| **СОРТ** | Пять ступеней. Растёт от выдержанного жара, задаёт цену за литр и доступ к покупателям. |
| **БАК** | Копит самогон. Переполнился — производство встало, пора продавать. Ёмкость растёт вместе с производством. |
| **ПЕТРОВИЧ** | Постоянный покупатель: берёт всё, всегда, по рынку, сорт не трогает. |
| **ГОСТИ** | Появляются сами на четверть часа. Платят до ×3.6, но требуют сорт и уносят его с собой. |
| **ПОХМЕЛЬЕ** | Заход начинается заново в обмен на мудрость. Мудрость множит производство навсегда. |

Касание само по себе не даёт ничего: спам по экрану бессмысленен.

Игра не наказывает за отсутствие — пока телефон в кармане, аппараты работают.

## Разработка

Flutter 3.24.3 / Dart 3.5.3.

```bash
flutter pub get
flutter analyze                                # должно быть пусто
flutter test                                   # 215 тестов
flutter run
```

Отдельные наборы (по умолчанию пропускаются):

```bash
flutter test --tags golden --run-skipped       # снимки экрана
flutter test --tags perf  --run-skipped        # замеры, на спокойной машине
```

Снимки пересобираются флагом `--update-goldens`. **Пересобрав — посмотреть
глазами**: снимок, обновлённый не глядя, перестаёт что-либо проверять.

### Баланс

```bash
dart run tools/balance_report.dart 4   # прогон 4 часов за трёх игроков
dart run tools/balance_sweep.dart      # перебор чисел под цели
```

Все настраиваемые числа — в `lib/content/balance.dart`. Цели, в которые
экономика обязана попадать, — в `lib/sim/balance_targets.dart`; их стережёт
`test/balance_test.dart`.

### Сборка

```bash
flutter build apk --release      # build/app/outputs/flutter-apk/
flutter build web --release      # build/web
```

### Отладка в браузере

```bash
python tools/serve.py
```

Свой сервер, а не `python -m http.server`: он запрещает кэширование и
вычищает service worker. Без этого браузер показывает старую сборку.

### Иконки

```bash
dart run tools/make_icons.dart
```

Пиксель-арт лежит строками прямо в `tools/make_icons.dart`.

## Устройство проекта

```
lib/
  models/      состояние: ресурсы, аппараты, улучшения, сорт, престиж
  engine/      правила игры — чистые функции, без побочных эффектов
  content/     что в игре есть: аппараты, улучшения, сорта, покупатели, события
  core/        сейвы, миграции, часы, форматирование чисел
  sim/         headless-симулятор и цели баланса
  providers/   Riverpod: склейка движка, времени и интерфейса
  ui/          экран гаража, пиксель-арт, виджеты
```

Четыре правила, на которых всё держится.

**Движок не знает про интерфейс.** `GameEngine` — чистые функции
`состояние → состояние`. Поэтому баланс проверяется тестами за секунды, а не
двадцатиминутным сеансом.

**Формула живёт в одном месте.** Оффлайн-доход однажды разъехался с обычным
тиком и переполнил бак в тысячу раз. Теперь и тик, и оффлайн идут через
`GameEngine.creditOffline`.

**Миграции сейвов заморожены.** `lib/core/save.dart` — цепочка v1→v5. Старый
шаг никогда не переписывается под новые формулы: он обязан читать то, что
реально лежит на диске у игрока. Дублирование кода там намеренное.

**В сейве лежат факты, а не оценки.** Сколько куплено и сколько нагнано —
факты. Доход, цены, мудрость — оценки, и они считаются заново при каждой
загрузке по числам из `lib/content/balance.dart`. Поэтому правка баланса
применяется к старым сейвам сама, без миграции.

Подробнее: [docs/DESIGN.md](docs/DESIGN.md) — почему игра устроена так,
[docs/ROADMAP.md](docs/ROADMAP.md) — состояние работ,
[docs/RELEASE.md](docs/RELEASE.md) — порядок выпуска.

## Публикация

Один раз в настройках репозитория: **Settings → Pages → Source: GitHub
Actions**.

Дальше каждый push в `main` пересобирает и выкладывает веб-версию —
[.github/workflows/deploy-web.yml](.github/workflows/deploy-web.yml). Сборка
занимает около двух минут.

Workflow **не прогоняет тесты**, только собирает. Поэтому перед вливанием в
`main` — `flutter analyze` и `flutter test` руками; полный порядок в
[docs/RELEASE.md](docs/RELEASE.md).

## Что дальше

Полный список с историей — [docs/ROADMAP.md](docs/ROADMAP.md). Здесь то, что
взято в работу, по убыванию пользы.

**Ближайшее**

- [ ] **Звук**: нажатие, покупка, продажа, перегрев, похмелье. Самое заметное
      из недостающего — игра пока немая.
- [ ] **ШУХЕР**: участковый на обходе. Единственная механика из дизайна,
      дающая напряжение, а не только накопление.
- [ ] **Реакции портрета** на состояние: перегрев, полный бак, простой.
      Сейчас портрет меняется только от эпохи.
- [ ] **Настройки**: звук и вибрация выключаемы.

**Потом**

- [ ] **Пуш-уведомления** — «бак полон», «на свадьбе ждут». Нужен плагин и
      запрос разрешения в правильный момент, а не при первом запуске.
- [ ] **Экран статистики**: за всё время, за заход, по аппаратам.
- [ ] **События с расходом**, а не только со сбытом: сахар подорожал, тёща
      приехала, участковый намекает.
- [ ] **Второй слой престижа** — на случай, если мудрости станет мало.
- [ ] **Достижения, открывающие механики**, а не только цифры.

**Требует Mac**

- [ ] Нативная сборка под iOS. Веб-версия закрывает потребность, поэтому
      задача не срочная.

**Сознательно не делается**

- Локализация. Игра для своих и по-русски.
- Магазины приложений. Раздача ссылкой и файлом.
- Монетизация.
