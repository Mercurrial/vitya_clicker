# Аудит графики и интерфейса — что сделано и что осталось

Рабочий файл на время переделки. После того как всё из раздела «Осталось»
закрыто, файл удаляется.

Ветка: `rashody`. Коммиты аудита идут после `d41a953` (неприятности).

---

## Как смотрели

Игру открывали в браузере (`python tools/serve.py`) на трёх размерах
экрана — 390×844, 320×640, 390×1600 — и на сейвах разных стадий:

- `dart run tools/demo_saves.dart` — сейвы начала, середины и конца игры;
- `dart run tools/moments.dart` — время гостя, участкового, сахара и тёщи;
- `?t=<миллисекунды>` в адресе — сдвиг часов страницы, чтобы увидеть событие
  сразу, а не ждать его по расписанию.

Сейв кладётся в `localStorage['flutter.vitya_save_v1']` со страницы того же
адреса, **но не из открытой игры** — игра перезапишет его при выгрузке.
Удобно класть с `/favicon.png`.

## Сделано

### Графика

- [x] Все 13 аппаратов нарисованы заново в `tools/sprite_lab.py`: у каждого
      свой силуэт, общая светотень. Раньше 7 старших ступеней делили одну
      заглушку, а у младших внизу было 3 пустых строки.
- [x] Сцена рисует все аппараты одним размером пикселя (шаг в полточки).
      Три новейших стоят крупно на полу, старшие — на полках у портрета.
- [x] Бирки с количеством больше не растягиваются на всю ширину полки.
- [x] Кирпич со швами и объёмом, виньетка, провод с выключателем.
- [x] Обстановка по стадиям: гараж (календарь, канистра, ящик), цех
      (трубы, плакат ТБ, щиток, крашеная панель), производство (окно в ночь,
      манометры, разметка).
- [x] Латунная табличка под портретом вместо текста по кирпичу.
- [x] Огонь только у аппаратов, которым он к лицу; у старших жар виден по
      свету в окнах. На полках огня нет.
- [x] Пар — клубами, и зависит от жара: остывший аппарат не парит.
- [x] 20 разных значков целей (`tools/goal_icons_lab.py`) вместо 9 на всех.
- [x] ▲▼ нарисованы, а не набраны: в шрифтах игры этих знаков нет.

### Экран и тексты

- [x] Продажа — янтарная кнопка. Гость рядом, с отсчётом; пока сорт не
      дотягивает — пишет, какой нужен, и свою реплику («не первач же»).
- [x] Кнопка продажи не горит, пока за бак не дадут хотя бы рубль.
- [x] Бак: «полный через 8 мин» вместо «хватит на 30 мин», которое не убывало.
- [x] Жар, серия и сорт — одна карточка; зона перегрева видна на шкале.
- [x] Обучение — в заголовке пульта, а не таблеткой поверх гаража.
- [x] Подсказка жара: «держи, греется», пока палец на экране; во время
      обхода — «ТИХО — отпусти».
- [x] Вкладки не режут «УЛУЧШЕНИЯ»; метки «есть что взять» над вкладками.
- [x] Покупка пачками — четыре кнопки вместо одной по кругу.
- [x] Магазин: спрайт в каждой строке, силуэт следующей ступени, названия
      ужимаются, а не обрезаются.
- [x] Улучшения отсортированы по цене, у каждого цветная метка оси.
- [x] Цели: подписи в ячейках и карточка «следующая цель».
- [x] Плашка «ЦЕЛЬ ВЗЯТА» со значком — раньше цели открывались молча.
- [x] Экран возвращения: пиксельный портрет вместо фото, честные подписи
      про потолок времени и полный бак.
- [x] Высота сцены зависит от экрана: на низком магазин не сжимается в
      строку, на высоком сцена не растягивается в пустую стену.
- [x] Форматы: «10К л» вместо «10.00К л», отсчёт «12:03» вместо «12 мин».
- [x] Первач больше не синий: бак первые полчаса выглядел налитым из-под крана.

### Баги

- [x] Крепкая рука, Трудовая мозоль и Дедовская хватка не делали ничего.
      Теперь расширяют окно жара (с потолком), объявлено в балансе v6.
- [x] Веб-версия жила по своему расписанию событий: хеш перемножал числа
      за 2^53. Переписан, закреплён тестом.
- [x] После подвисания кадра жар прыгал из холодного в перегрев.
- [x] Экран возвращения писал «бак полон», когда автопродажа уже его сдала.
- [x] «Тонна за плечами» проверяла миллион литров → «Своё озеро».
- [x] Мёртвый переключатель «ПИКСЕЛЬ / ПЛАКАТ» убран.

### Тесты
