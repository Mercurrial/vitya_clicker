## Технические решения (принимаются один раз)

| Решение | Выбор | Обоснование |
|---|---|---|
| **Числа** | `double`, вся арифметика и формат — в одном модуле | Потолок `1.79e308` недостижим для нашего масштаба. Изоляция позволит подменить на big-number без переписывания логики |
| **Формат чисел** | Русские суффиксы: 1.5К, 2.3М, 4.2Б, Т, Квд… | Научная нотация (`4.20e23`) убивает тёплый тон |
| **Сохранения** | JSON + **поле версии** + цепочка миграций, автосейв | Без версионирования с первого дня любое изменение ломает сейвы игроков |
| **Хранилище** | `shared_preferences` (один JSON-блоб) | Сейв маленький; Hive избыточен |
| **Время** | UTC epoch, оффлайн-дельта с потолком, защита от отката часов | Перевод часов назад → не начисляем, просто обновляем метку |
| **Оффлайн-доход** | Считается от состояния: `f(state, elapsed)`, потолок ~8–12 ч | Продакшн должен быть чистой функцией состояния |
| **Контент** | Генераторы/апгрейды/достижения/реплики — **данными**, не в виджетах | Баланс правится без касания кода |
| **Строки** | Централизованы в одном месте | Готовность к локализации, единый тон |
| **Игровой цикл** | Один тикер, ленивый расчёт от прошедшего времени, реакция на сворачивание | Батарея и корректность на мобилке |
| **Хаптика** | `HapticFeedback` из `flutter/services` | Встроено, плагин не нужен |

## Фаза 0 — Фундамент 🔍 **ИНСПЕКЦИЯ**

Всё остальное стоит на этом. Правится потом дороже всего.

- [ ] Переименование проекта, bundle id (`com.<...>.vityagonit`)
- [ ] Модуль чисел: арифметика + русский формат (1.5К / 2.3М / 4.2Б)
- [ ] Сейв: версионированный JSON, миграции, автосейв, безопасная загрузка
- [ ] Сервис времени: UTC, оффлайн-дельта, потолок, защита от отката
- [ ] Контент как данные (генераторы, апгрейды — из описаний)
- [ ] Жизненный цикл приложения (пауза / возврат)
- [ ] Чистка мёртвого кода от KARDASHEV

## Фаза 1 — Ядро и ощущение 🔍 **ИНСПЕКЦИЯ**

Здесь решается, приятно ли играть. Поверх ляжет вся игра.

- [ ] Тёплый мультгараж: палитра, типографика, компоненты
- [ ] Витя (заглушка → фото) как главный объект
- [ ] Тап + **сок**: squash&stretch, брызги, вылетающая цифра, хаптика
- [ ] **ГРАДУС**: шкала, зелёная зона ×3, перегрев, спад
- [ ] Генераторы: покупка, milestones ×2, разблокировка тиров
- [ ] Апгрейды: персональные, глобальные, синергии
- [ ] Экран: доход/сек, баланс, вкладки

## Фаза 2 — Мета 🔍 **ИНСПЕКЦИЯ**

Форма экономики; после неё баланс менять дорого.

- [ ] **ПОХМЕЛЬЕ**: сброс, Мудрость, перманентный множитель
- [ ] **Превью престижа до разблокировки** (+19 % к D7)
- [ ] Достижения: буст + встроенный гайд
- [ ] Балансировка симулятором под 25–35 мин до первого престижа

## Фаза 3 — Жизнь и юмор

- [ ] **Витя-цитатник**: контекстные реплики, очередь без повторов
- [ ] Случайные события (свадьба, сахар подорожал, тёща)
- [ ] **ШУХЕР** + участковый Николай Петрович
- [ ] Реакции портрета Вити на состояние

## Фаза 4 — Удержание

- [ ] Оффлайн-доход + экран возвращения («Витя нагнал 12К литров»)
- [ ] Пуш-уведомления + **правильный момент запроса** (после первой победы)
- [ ] Реплики Вити в пушах

## Фаза 5 — Полировка и выпуск

- [ ] Звук: тап, покупка, открытие, событие, престиж
- [ ] Настройки: звук, хаптика, пуши, сброс
- [ ] Экран статистики
- [ ] Иконка, splash, подписи, сборка релиза
- [ ] Финальный проход по балансу
