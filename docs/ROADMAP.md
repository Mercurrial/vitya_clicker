# ВИТЯ ГОНИТ — дорожная карта

Дизайн игры: [DESIGN.md](DESIGN.md). Здесь — что сделано, что нет и почему.

Отмечено честно: `✅` работает и покрыто тестами, `◐` работает частично,
`⬜` не начато, `✖` сознательно выброшено.

---

## Состояние

Игра **играбельна от начала до похмелья и собирается в APK**. Тестов — 130,
плюс отдельный набор снимков экрана (`flutter test --tags golden --run-skipped`).

Что осталось до «полноценного релиза»: звук, случайные события, ШУХЕР,
пуш-уведомления. Ни одно из этого не мешает дать поиграть другу.

---

## Технические решения (приняты, не пересматриваются без повода)

| Решение | Выбор | Обоснование |
|---|---|---|
| **Числа** | `double`, арифметика и формат — в одном модуле | Потолок `1.79e308` недостижим для нашего масштаба |
| **Формат чисел** | Русские суффиксы: 1.5К, 2.3М, 4.2Б | Научная нотация (`4.20e23`) убивает тёплый тон |
| **Сохранения** | JSON + поле версии + цепочка миграций (сейчас v4) | Без версионирования с первого дня любое изменение ломает сейвы |
| **Миграции** | Замораживаются навсегда, дублирование в них намеренное | Старый шаг обязан читать то, что реально лежит у игрока на диске |
| **Хранилище** | `shared_preferences`, один JSON-блоб | Сейв маленький; Hive избыточен |
| **Настройки** | Отдельно от сейва, ключ-значение | Галочка в настройках не стоит поднятия версии формата |
| **Время** | UTC epoch, оффлайн-дельта с потолком, защита от отката часов | Перевод часов назад → не начисляем, просто обновляем метку |
| **Оффлайн-доход** | `GameEngine.creditOffline` — тот же тик, что и обычный | Однажды разъехалось и переполнило бак в тысячу раз |
| **Движок** | Чистые функции `состояние → состояние`, без интерфейса | Баланс проверяется тестами за секунды, а не сеансом на 20 минут |
| **Контент** | Генераторы/апгрейды/достижения/реплики — данными | Баланс правится без касания кода |
| **Графика** | Пиксель-арт строками прямо в исходнике | Видно в диффе, правится символом, не нужен художник |
| **Вёрстка** | Проверяется снимками всего экрана | Три переполнения нашлись только так |
| **Строки** | Пока по месту | Локализация не планируется: игра для своих и по-русски |
